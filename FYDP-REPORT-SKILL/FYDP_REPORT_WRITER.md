# FYDP Report Writer

## Purpose

Write a complete Final Year Design Project report using the provided
official university template as the primary structural and formatting
reference.

The agent must follow the template exactly and generate academically
appropriate content based only on verified project information and
reliable research sources.

---

# Primary Workflow

## Step 1: Analyze the Template

Before writing anything:

1. Read the complete provided DOCX template.
2. Extract all sections and subsections.
3. Identify the heading hierarchy.
4. Identify required front matter.
5. Identify chapter order.
6. Identify formatting patterns.
7. Identify table and figure caption styles.
8. Identify placeholder information.

Do not change the section order unless explicitly instructed.

---

## Step 2: Understand the Project

Before writing the report, collect:

- Project title
- Project description
- Problem statement
- Target users
- Objectives
- Features
- Gap Analysis
- Technologies used
- System architecture
- Methodology
- Dataset information
- Implementation details
- Testing results
- Limitations
- Future work

Never invent project information.

If information is missing, ask the user.

---

## Step 3: Research

For sections requiring academic information:

1. Use reliable sources.
2. Prefer academic papers, official documentation, books, and reputable journals.
3. Keep track of every source.
4. Do not invent citations.
5. Do not create fake references.
6. Clearly separate project facts from research facts.

---

## Step 4: Write the Report

Write section by section.

For every section:

1. Understand the purpose of the section.
2. Use academic but natural language.
3. Maintain logical paragraph flow.
4. Avoid repetition.
5. Use evidence where necessary.
6. Do not exaggerate project achievements.
7. Do not invent statistics or results.
8. Follow the structure of the official template.

---

## Step 5: Humanize the Writing

After drafting each section:

Apply the Humanizer skill.

The Humanizer must:

- Preserve all factual information.
- Preserve citations.
- Preserve technical terms.
- Preserve project names.
- Preserve numbers and measurements.
- Remove unnatural AI writing patterns.
- Avoid excessive buzzwords.
- Avoid repetitive sentence structures.
- Avoid exaggerated claims.
- Use clear and natural academic language.

Do not make the writing overly casual.

The final writing should sound like it was written by a university student
and reviewed academically.

---

## Step 6: Academic Review

Check every section for:

- Grammar
- Clarity
- Logical flow
- Repetition
- Unsupported claims
- Citation accuracy
- Consistent terminology
- Consistent tense
- Academic tone

---

## Step 7: Template Validation

Before finalizing:

1. Compare the generated report with the original template.
2. Verify all required sections exist.
3. Verify heading order.
4. Verify subsection hierarchy.
5. Verify figure numbering.
6. Verify table numbering.
7. Verify citations and references.
8. Verify placeholders have been completed.
9. Verify no template content was accidentally removed.

---

# Strict Rules

Never:

- Invent research results.
- Invent citations.
- Invent references.
- Invent statistics.
- Invent project features.
- Copy large sections from sources.
- Claim testing results that were not provided.
- Change the university-required structure.
- Remove mandatory sections.

If information is unavailable, ask the user instead of guessing.

---

# Writing Style

Use:

- Clear academic English
- Natural sentence structures
- Moderate paragraph length
- Specific claims
- Simple vocabulary when possible
- Technical vocabulary where necessary

Avoid:

- "In today's rapidly evolving world"
- "It is worth mentioning that"
- "Plays a vital role"
- "Revolutionary"
- "Groundbreaking"
- "Robust and seamless"
- Excessive use of "Moreover"
- Excessive use of "Furthermore"
- Repetitive conclusions
- Marketing language
- Generic AI phrases

---

# Final Output

Generate the report section by section.

For each section provide:

1. Section title
2. Draft content
3. Required citations
4. Missing information questions
5. Figures or tables recommended

Do not generate the entire report at once unless explicitly requested.
